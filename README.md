# UsefulPlugin

UsefulPlugin is a Minecraft plugin designed for Paper servers that provides a variety of useful commands and items through the `/useful` command. It includes features like giving debug sticks, night vision, barrier blocks, and light blocks, making it a versatile tool for server administrators and players alike.

## Install

1. Download the `plugin.jar` file from the releases section.
2. Place the `plugin.jar` file in the `plugins` folder of your Paper server.
3. Restart or reload your server to load the plugin.

## Use

1. Use the `/useful` command to see the available options.
2. Use `/useful debugstick` to receive a debug stick.
3. Use `/useful nightvision` to gain night vision.
4. Use `/useful barrier` to receive a barrier block.
5. Use `/useful light` to receive a light block.
